# TASK06（改訂版）: 図鑑・コレクション画面と既存パンダ紹介ページの連携

## 参照仕様書
- docs/スタンプ探索機能_仕様書.md（3-5、3-5-1）
- docs/レッサーパンダマスコット_デザイン仕様書.md（8章）

## 重要な前提（改訂理由）
当初のTASK06は「実写プロフィール画面を新規に作る」想定だったが、
`app/pandas/`配下に12頭分の紹介ページ（一覧・詳細4タブ・家系図）が
既に完成していることが判明した。実写プロフィール画面は新規作成せず、
**既存の`app/pandas/`をそのまま活用し、探索ゲームの「発見」と
接続する**方針に変更する。

## やること（一つずつ進める）

1. **CC-BY-4.0クレジット表記の確認・追加**
   - `lib/pandaData.ts`のデータ、または`app/pandas/`のUI内に、
     鯖江市オープンデータの出典クレジット（例：「写真提供：
     鯖江市データシティ鯖江ポータルサイト」）が表示されているか確認する
   - 表示されていなければ、一覧ページと詳細ページの両方に追加する

2. **スポットとパンダIDの対応表を作る**
   - 例：`lib/spotPandaMapping.ts`
   - 14の出現ポイント（`spawnPoints.ts`）と、`LESSER_PANDAS`の
     12頭の`id`を対応付ける
   - 今回はランダム割当の仮実装でよい（正式な対応表は後日決定）
   - スポット数14に対してパンダは12頭なので、一部のパンダは
     複数スポットに割り当てられる形で構わない

3. **図鑑・コレクション画面のUI**
   - 例：`app/collection/page.tsx`
   - 見開きの絵本ページ風レイアウトで、全スポット（14件）を一覧表示
   - 未発見のスポットはシルエット表示、発見済みはカラー表示
     （TASK04の`ExplorationState`から取得済み状態を判定）
   - 発見済みスポットのカードには、対応する実写パンダのサムネイル
     （`photoUrl`）を小さく添える

4. **発見からパンダ詳細ページへの導線**
   - 図鑑画面で発見済みスポットをタップすると、対応する
     `app/pandas/[id]/`に遷移する
   - TASK04のチェックイン取得演出（`DiscoveryOverlay`）の直後にも、
     「このパンダについてもっと見る」ボタン等で`app/pandas/[id]/`
     への導線を追加する

## 完了条件

- [ ] 14スポットとパンダIDの対応表がある（仮実装で可）

- [ ] 発見済みスポットから、対応する`app/pandas/[id]/`の

- [ ] チェックイン取得演出から、パンダ詳細ページへの導線がある
- [ ] TypeScriptの型エラー・ESLintエラーがない
